# Student Management System

A REST API for creating, reading, updating, and deleting student records.

## Technology stack

- Java 17
- Spring Boot 3.5.5
- Spring MVC for HTTP endpoints
- Spring Data JPA and Hibernate for persistence
- PostgreSQL with the PostgreSQL JDBC driver
- Maven for dependency management and running the application

This is a single Spring Boot application; it has no separate frontend or microservices.

## Setup and run

### Requirements

- JDK 17
- PostgreSQL
- Maven (or use the Maven wrapper if one is added to the project)

### Configure PostgreSQL

Create the database:

```sql
CREATE DATABASE student_db;
```

In `src/main/resources/application.properties`, configure the PostgreSQL URL, username, and password for your local database. The default URL is `jdbc:postgresql://localhost:5432/student_db`. Hibernate is configured to update the database schema automatically when the application starts.

### Start the application

From the project root, run:

```bash
mvn spring-boot:run
```

The API is available at `http://localhost:8080`. To build the application without starting it, run `mvn clean package`.

## REST API

All endpoints use the `/students` base path and exchange JSON.

| Method | Endpoint | Description | Success response |
|---|---|---|---|
| `POST` | `/students` | Create a student | `201 Created` with the student |
| `GET` | `/students` | List all students | `200 OK` with an array |
| `GET` | `/students/{id}` | Get one student | `200 OK`; `404 Not Found` if missing |
| `PUT` | `/students/{id}` | Replace a student's editable fields | `200 OK`; `404 Not Found` if missing |
| `DELETE` | `/students/{id}` | Delete a student | `204 No Content`; `404 Not Found` if missing |

Student JSON fields are `name`, `email`, `age`, and `course`. The `id` is generated by the database.

Example create request:

```bash
curl -X POST http://localhost:8080/students \
  -H 'Content-Type: application/json' \
  -d '{"name":"Avery Chen","email":"avery@example.com","age":20,"course":"Computer Science"}'
```

Example response:

```json
{
  "id": 1,
  "name": "Avery Chen",
  "email": "avery@example.com",
  "age": 20,
  "course": "Computer Science"
}
```

## Architecture

The application uses a layered architecture:

```text
HTTP client
    |
    v
StudentController       Maps REST requests and HTTP responses
    |
    v
StudentService          Holds student CRUD operations
    |
    v
StudentRepository       Spring Data JPA database access
    |
    v
PostgreSQL              Persists Student records
```

Code is organized under `src/main/java/com/example/studentmanagement/`:

```text
StudentManagementApplication.java  Spring Boot entry point
controller/StudentController.java   REST routes under /students
service/StudentService.java         CRUD application logic
repository/StudentRepository.java   JpaRepository for Student
entity/Student.java                 JPA entity mapped to a database table
```

`StudentController` delegates work to the service; the service uses `StudentRepository`, which provides database operations through Spring Data JPA. The `Student` entity has an auto-generated ID and the fields `name`, `email`, `age`, and `course`.
